# Security Policy

This security policy applies to public projects under the [Snapcast organization](https://github.com/snapcast) on GitHub.

## Reporting a Vulnerability

We encourage responsible disclosure of security vulnerabilities.
If you find something suspicious, we encourage and appreciate your report!

### Ways to report

In order for the vulnerability reports to reach maintainers as soon as possible, the preferred way is to use the "Report a vulnerability" button under the "Security and quality" tab of the associated GitHub project.
This creates a private communication channel between the reporter and the maintainers.
